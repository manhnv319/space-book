# Dữ liệu đơn vị hành chính Việt Nam

- **Nguồn**: https://github.com/ThangLeQuoc/vietnamese-provinces-database
- **File gốc**: `json/vn_only_simplified_json_generated_data_vn_units_minified.json`
- **Giấy phép**: MIT
- **Gốc dữ liệu**: API của Tổng cục Thống kê (General Statistics Office of Vietnam)
- **Tải về**: 2026-07-27, release v4.0.0
- **Cấu trúc**: 34 tỉnh/thành, 3.321 phường/xã — hai cấp, **không có cấp huyện**
  (bỏ từ 01/07/2025).

Bundle trong repo thay vì gọi API bên thứ ba lúc chạy: địa chỉ giao hàng không
được phụ thuộc vào một dịch vụ miễn phí có thể chết. File chỉ đọc phía server,
không bao giờ gửi nguyên khối xuống trình duyệt.

## Cập nhật

Tải lại file trên từ release mới nhất và ghi lại ngày ở đây.
